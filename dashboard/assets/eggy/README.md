# Eggy

The official mascot. `eggy_original.webp` is the supplied artwork, byte for byte (1024×1536). The other files are plain resized copies of it
(`eggy_400.webp`, `eggy_200.webp`) and rounded-square app-icon renderings that place the whole, uncropped character on its own white background
(`eggy_icon_128.png`, `eggy_icon_48.png`). Nothing was redrawn or regenerated. Do not replace the character.
